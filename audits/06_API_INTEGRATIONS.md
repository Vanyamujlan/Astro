## 1. Реестр внешних интеграций

### 1.1. Telegram Bot API и Telegram Stars
- **Назначение:** взаимодействие с пользователями, приём оплаты в цифровой валюте Telegram Stars (`XTR`), отправка изображений и PDF-документов.
- **Библиотека:** `python-telegram-bot[job-queue,rate-limiter]` (план).
- **Ключевые методы API (планируются):**
  - `getUpdates` / `setWebhook` (получение событий).
  - `sendMessage`, `sendPhoto`, `sendDocument`, `editMessageText`.
  - `sendInvoice` (валюта `XTR`, `provider_token=""`), `answerPreCheckoutQuery`, обработка `SuccessfulPayment`.
- **Конфигурация (переменные `.env`):**
  - `BOT_TOKEN` — токен бота от BotFather (секрет, в код не попадает).
  - `USE_WEBHOOK`, `WEBHOOK_URL` — опционально для продакшена.
- **Стоимость:** Бесплатно (Telegram удерживает свою комиссию при выводе Stars согласно правилам платформы).
- **Статус:** Запланировано.

### 1.2. OpenAI-Compatible LLM API
- **Назначение:** литературная интерпретация заранее вычисленных астрологических и нумерологических данных.
- **Библиотека:** официальный асинхронный клиент `openai` (`AsyncOpenAI`).
- **Ключевые методы:** `chat.completions.create` (с передачей `usage` для учёта токенов).
- **Конфигурация (переменные `.env`):**
  - `AI_API_KEY` — ключ доступа к выбранному провайдеру (секрет).
  - `AI_BASE_URL` — адрес API (позволяет без правки кода переключаться между OpenAI, OpenRouter, DeepSeek, Groq или локальным сервером).
  - `AI_MODEL_FAST` — экономичная модель для коротких прогнозов.
  - `AI_MODEL_PRO` — продвинутая модель для глубоких разборов и PDF.
  - `AI_DAILY_BUDGET_USD` — жёсткий дневной лимит расходов.
- **Стоимость:** Оплата за токены согласно тарифам выбранного провайдера; минимизируется за счёт кэширования в БД и разделения моделей.
- **Статус:** Запланировано.
